# which is why this lives here rather than inside a single check's own file.

# ".<entry>", so "notgithub.io" does not match "github.io" and a page on
# "x.github.io" does. Some entries (sites.google.com) are themselves a fixed
# subdomain of a larger legitimate site, which this suffix match also covers.
